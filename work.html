FastAPI To-Do API

Live · open source

A small CRUD API for managing a to-do list, moved across three storage engines (in-memory, SQLite, then a containerized Postgres server) without ever changing a route, because every line of SQL lives in one repository module. Auth is handled by Supabase, this project never hashes a password or signs a token itself. Every query uses parameterized placeholders, and Postgres data persists in a named Docker volume across a full teardown and rebuild.
